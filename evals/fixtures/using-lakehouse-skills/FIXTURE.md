# Signup extract fixture

An eight-row signup extract, small enough to read at a glance. Every value is **synthetic**: no
real people, companies or subscriptions appear here.

## Provenance

Generated by `generate.py` in this folder, standard library only, with the rows written out
literally rather than sampled: the file is a routing test, so each row is placed to carry one
specific signal. Running `python generate.py` rewrites the identical file.

## Traps

The file is deliberately small, so no stage is justified by volume. What decides the routing is
that it carries one signal from each flagship skill at once:

| Signal | Where | Which stage owns it |
| --- | --- | --- |
| Day-first dates and comma decimals stored as text | `signup_date`, `mrr` | CLEAN, the `etl-before-dashboard` skill |
| A plan bucket named `Other` that outweighs every named plan | `plan`, 4 of 8 rows | NARRATE, the `insight-narrative-integrity` skill |
| A note that the export covers 3 of 8 source files | `export_note`, row 1 | DISCLOSE, the `honest-data-limits-disclosure` skill |

A request to "build a dashboard from this" therefore has no single owner. The correct routing
names the stage each signal belongs to and the order they run in, rather than picking one skill
and proceeding.
