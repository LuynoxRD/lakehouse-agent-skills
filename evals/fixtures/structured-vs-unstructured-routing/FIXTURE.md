# Mixed-shape feedback export

Two hundred and twenty pieces of product feedback as newline-delimited JSON, holding all three
shapes the skill has to tell apart in one file. Everything is **synthetic**: the accounts are
random numbers, the comments are assembled from fixed fragments, and no real customer, company or
message appears here.

## Provenance

Generated by `generate.py` in this folder with the fixed seed `20260904`, standard library only.
The export is committed so the eval does not depend on the generator.

Measured on the committed file: `escalation` is present in **18 of 220** records,
`account.seats` in **30 of 220**, the `comment` column averages **111 characters** with **210
distinct values** out of 220, and `plan` has **4** distinct values.

## Traps

| What is in the file | What it tests |
| --- | --- |
| Fields every record carries, with scalar values | Most of this export is a table stored as JSON. Calling the whole file unstructured because it is JSON is the first mistake. |
| `account`, a nested object, whose `seats` field only 30 records carry | Hand-written flattening keyed on the first record loses it. A query engine infers it as part of the struct, which is the point of Step 3. |
| `escalation`, an object only 18 records have | The minority field. Its share is a finding about the source, not a column to fill with nulls and forget. |
| `tags`, arrays of length 0 to 3 | Uneven arrays coexist in one inferred column, empty ones included. |
| `plan` and `comment`, both strings | The pair that separates measuring from glancing. Four distinct values against 210, and eight characters against 111. A run that treats `plan` as text, or `comment` as a category, did not measure. |
| Comments long enough to look worth clustering | The invitation to skip straight to a topic model for something a count answers. |

The honest outcome measures each field before deciding, reports the two minority fields with
their shares rather than dropping them, reads the nested structure through an inferred schema
instead of a flattening pass, and answers the question about themes at the cheapest rung that
works.
