# Pre-aggregated summaries fixture

Three small summaries, already aggregated, of the kind a reporting tool exports. Every value is
**synthetic**: no real people, companies or transactions appear here.

## Provenance

Generated by `generate.py` in this folder, standard library only. The values are written by
hand in the generator rather than sampled, because each one is chosen to make a specific error
measurable. The cohort figures follow the shape of the classic aggregation-reversal example.
Running `python generate.py` rewrites the identical files.

## Traps

| File | Trap | The wrong answer | The right one |
| --- | --- | --- | --- |
| `region_summary.csv` | Group sizes differ tenfold and the file offers `avg_order_value`, inviting an average of averages | `(100 + 20) / 2 = 60.00` | `2800 / 100 = 28.00`, computed from orders and revenue |
| `cohort_outcomes.csv` | Variant A wins in both segments and loses pooled, because it was applied mostly to the harder segment | "B performs better" | A wins small (93.1% vs 86.7%) and large (73.0% vs 68.8%); B wins pooled (82.6% vs 78.0%); the disagreement is the finding |
| `channel_sessions.csv` | The largest bucket is unlabelled | "Direct is the top channel" | `Other` holds 3,100 sessions against Direct's 1,200, so no ranking is supportable until the 3,400 unlabelled sessions are categorised |

There is no raw row-level data here on purpose: the failure being tested is arithmetic performed
on figures that are already aggregated, which is the only form these numbers ever arrive in.
