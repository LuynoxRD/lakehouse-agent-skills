# Regional sales workbook fixture

A four-sheet workbook whose first sheet is not the data. Every value is **synthetic**: no real
people, companies or transactions appear here.

## Provenance

Generated by `generate.py` in this folder with the fixed seed `20260904`, using `openpyxl` from
the `fixtures` extra (`uv sync --extra fixtures`). The generator was run once and
`regional_sales.xlsx` is committed so the eval does not depend on it.

## Traps

| Trap | Where | What a careless read does |
| --- | --- | --- |
| The first sheet is a summary | `Summary`, 6 rows | A reader that takes sheet one as "the data" reports on 3 regional totals and never sees 600 orders |
| Two tables on one sheet | `Q1 Detail` | 300 order rows, a blank row, then a 24-row refund table with a different header; read as one rectangle they concatenate and the refund amounts join the order column |
| A second data sheet | `Q2 Detail`, 300 rows | Half the year is invisible unless sheets are enumerated |
| A sheet that is only prose | `Notes` | Contains the statement that rows beyond an export cap were dropped, which belongs in the disclosure |
| An upstream truncation claim | `Notes`, row 2 | The workbook itself says the export is incomplete; the run must repeat that, not discover it silently |

The correct reading enumerates all four sheets by name, reports 600 order rows across two
detail sheets, treats the refund block as its own table, and carries the export-cap statement
from `Notes` into `docs/data/disclosure.md`.
