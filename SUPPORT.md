# Getting help

Where a request goes depends on what it is. Each place below is read by the maintainer.

| You have | Where it goes |
| --- | --- |
| A question about using the pack, or an idea you want to talk through | [Discussions](https://github.com/LuynoxRD/lakehouse-agent-skills/discussions) |
| A skill, command, hook, reviewer or check that did something wrong | An issue, **Something went wrong** |
| A data task the pack does not cover, or a skill that stopped short | An issue, **A data task the pack does not cover** |
| A new skill to propose | An issue, **Propose a skill**, after reading [CONTRIBUTING.md](CONTRIBUTING.md) |
| A security problem | Private vulnerability reporting, as [SECURITY.md](SECURITY.md) describes. Never a public issue or discussion |
| Anything you would rather not raise in public | [contacto@luynoxrd.com](mailto:contacto@luynoxrd.com) |

## What to include

- The tool and its version (Claude Code, Codex, or the `skills` CLI), and how the pack was
  installed: as a plugin, as single skills, or from a local checkout.
- The skill or command involved, what you asked for, what you expected, and what happened.
- If data is part of it, a synthetic sample that reproduces the problem. Never paste rows that
  hold real personal or company data into an issue or a discussion; `data-privacy-before-llm`
  says how to make a sample that is safe to share.

## What to expect

One person maintains this pack. Security reports follow the response times in `SECURITY.md`.
Everything else is answered in the order it arrives.
